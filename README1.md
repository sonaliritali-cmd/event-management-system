# Event Management System

A web-based Event Management System built using
HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- Responsive event website
- Event search and categories
- Event booking form
- PHP and MySQL database connection
- Booking record storage

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## How to Run Locally
1. Install XAMPP.
2. Copy the project into htdocs.
3. Start Apache and MySQL.
4. Import database.sql using phpMyAdmin.
5. Open the project through localhost in your browser.
